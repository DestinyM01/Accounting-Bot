## Task 1 — Fix Export CSV button vertical alignment

**Files:**
- Modify: `web/src/app/pages/transactions/transactions.component.scss` (lines 99–117)

**Issue:** The filter row uses `align-items: center`. The filter groups (Category, Type, From, To) are `flex-direction: column` with a label + input stacked, making them taller than the button. `align-items: center` places the button's midpoint at the row's midpoint — which is above the input's baseline. Adding `align-self: flex-end` pins the button's bottom to the row's bottom, matching the inputs visually.

- [ ] **Step 1: Add `align-self: flex-end` to `.export-btn`**

  Find in `web/src/app/pages/transactions/transactions.component.scss`:
  ```scss
  .export-btn {
    display: flex;
    align-items: center;
    gap: 6px;
    background: var(--accent);
    color: #fff;
    border: none;
    border-radius: 10px;
    padding: 10px 18px;
    font-size: 0.875rem;
    font-family: var(--font-body);
    font-weight: 600;
    cursor: pointer;
    white-space: nowrap;
    transition: opacity 0.13s;
    mat-icon { font-size: 1.1rem; width: 1.1rem; height: 1.1rem; }
    &:hover { opacity: 0.85; }
    &:focus-visible { opacity: 0.85; outline: 2px solid var(--color-focus); outline-offset: 2px; }
  }
  ```
  Replace with:
  ```scss
  .export-btn {
    display: flex;
    align-items: center;
    gap: 6px;
    align-self: flex-end;
    background: var(--accent);
    color: #fff;
    border: none;
    border-radius: 10px;
    padding: 10px 18px;
    font-size: 0.875rem;
    font-family: var(--font-body);
    font-weight: 600;
    cursor: pointer;
    white-space: nowrap;
    transition: opacity 0.13s;
    mat-icon { font-size: 1.1rem; width: 1.1rem; height: 1.1rem; }
    &:hover { opacity: 0.85; }
    &:focus-visible { opacity: 0.85; outline: 2px solid var(--color-focus); outline-offset: 2px; }
  }
  ```
  Only one line added (`align-self: flex-end;`). Nothing else changes.

## Task 3 — Budget category progress bars: use category color

- Modify: `web/src/app/pages/budget/budget.component.html` (lines 101–105)

**Issue:** The per-category budget progress bars use `budgetBarColor(b.percentage)` which returns green/red based on spend percentage. The user wants the fill color to reflect the category's own identity color. The warning signal stays via the percentage text color (`.cbc-pct [style.color]`), which already uses `budgetBarColor(b.percentage)` — that line does NOT change.

**Assumption:** `catColor(b.category)` is already defined in `budget.component.ts` and returns the category's hex color string (same function used for the icon wrap background). The hero total bar (`[style.background]="budgetBarColor(totalPct)"` at line 37) is left unchanged — there is no single category color for the aggregate total.

- [ ] **Step 1: Change per-category bar fill color binding**

  Find in `web/src/app/pages/budget/budget.component.html` (lines 101–105):

  ```html
                 [style.transform]="'scaleX(' + b.percentage / 100 + ')'"
                 [style.background]="budgetBarColor(b.percentage)">
            </div>
          </div>
  ```
